Import Dữ Liệu Từ Excel

Nạp hàng loạt dữ liệu từ file .xlsx hoặc .csv. Dòng đầu tiên phải là tiêu đề cột (đúng tên như file mẫu).
Tải File Lên
Tối đa 10 MB. Dòng 1 là tiêu đề; các dòng sau là dữ liệu.
Lưu ý
  • Kho Máy: trùng serial_no sẽ được cập nhật (không tạo trùng).
  • Nhân Viên: trùng id sẽ được cập nhật.
  • Đơn Giao / Thu Hồi: mỗi dòng tạo một bản ghi mới (mã tự sinh).
  • Dòng thiếu cột bắt buộc sẽ bị bỏ qua và báo lại.
